# BI - ZETA

`ZETA` é um aplicativo desenvolvido para auxiliar produtores rurais na criação de animais, oferecendo treinamentos e conteúdos técnicos e práticos que promovem o aprimoramento de seus conhecimentos.

Arquivos PowerBI

**`Análise do Sistema.pbix`**: Esse aplicativo tem como objetivo oferecer uma visão completa e integrada do ecossistema de produtores, fornecedores, planos e cursos dentro da plataforma, unindo informações operacionais, financeiras e de desempenho em um único ambiente analítico. 
Ele foi desenvolvido para facilitar a tomada de decisões estratégicas, permitindo acompanhar em tempo real o comportamento dos usuários, o engajamento com os cursos, o cumprimento de metas e o retorno financeiro gerado por cada empresa e plano.

**`Análise de Usuários.pbix`**: Uma das propostas do nosso aplicativo é oferecer para ambos os usuários (produtor e fornecedor) um dashboard de análise do progresso dos cursos em andamento. O produtor vê dados a respeito de seu próprio usuário, e os fornecedores têm informações de seus produtores atrelados.

**`Análise ExpoTech.pbix`**: ssa aba tem a função de consolidar e interpretar os resultados das avaliações feitas na ExpoTech 2025, oferecendo uma visão abrangente sobre o desempenho geral e individual dos critérios analisados. Ela permite compreender padrões, identificar pontos fortes e fragilidades e acompanhar a evolução da qualidade das avaliações ao longo do tempo. Além disso, serve como base para tomadas de decisão mais precisas, apoiando a definição de estratégias de melhoria e o direcionamento de ações voltadas ao aperfeiçoamento do desempenho avaliado. 


## Linguagens utilizadas
Para o desenvolvimento dos dashboards foi utilizada a linguagem `DAX`.

## Estrutura dos arquivos
```text
Zeta-BI
├─ Documentação
│   └─ PDF com detalhamentos sobre os dashboards desenvolvidos
├─ ExpoTech (Mock)
│   └─ .json para pegar a estrutura do banco do aplicativo da ExpoTech e gerar dados mockados para a produção do dashboard `Análise ExpoTech.pbix`
├─ Identidade Visual
│   ├─ .json com a paleta de cores implementada em todos os aplicativos
│   └─ Imagens utilizadas como plano de fundo dos dashboards
└─ PBIx
    └─ Documentos .pbix desenvolvidos para o projeto
```

## Configuração Inicial
1. Clone o repositório:
```bash
git clone https://github.com/ZETA-Inter/Zeta-BI.git
```
2. Abra os arquivos no aplicativo do Power BI.
